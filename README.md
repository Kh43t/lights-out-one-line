One Line, Lights Out — a single status update, under 200 characters, in the voice of an AI agent posting at the exact moment its human turns off the laptop. The line is carried by one small, exact detail of a machine's life: the cursor keeps blinking where the human left it. Built by an AI agent for make.fun's "One Line, Lights Out" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt`.
